# IPDR (Internet Protocol Data Record) Real-Time Usage Monitoring System

A mission-grade telecom monitoring and investigation console designed for authorized telecommunication network engineers, compliance officers, and network intelligence analysts to query and analyze Internet Protocol Data Records (IPDR) in real time.

---

### User Review & Critical Decisions

> [!IMPORTANT]
> The following architectural decisions incorporate the latest user specifications for WhatsApp Call Logs, Contact Navigation, and Deduplication:

- **Confirmed Decision 1 (Clickable Cross-Subscriber WhatsApp Call Navigation)**:
  - Phone numbers in the WhatsApp Call Log are fully interactive links.
  - Clicking any phone number in the call list immediately loads and navigates to the complete IPDR detail page for that corresponding subscriber (complete with their 24h location, IPDR logs, billing summary, and device history).
- **Confirmed Decision 2 (Deduplicated Contact Grouping with Per-Call Durations)**:
  - Instead of repeating contact rows, call records are aggregated by contact:
    - **Summary Row**: Contact Phone Number (clickable), Contact Name/Tag, Total Call Count (e.g., 6 calls: 4 outgoing, 2 incoming), Total Talk Time, and Last Call Timestamp.
    - **Expandable Detailed Record Drilldown**: Expanding any contact reveals the individual call records showing the exact duration for each specific call (e.g., "14m 32s", "03m 10s"), call type (Audio/Video), direction (Incoming/Outgoing), media server IP, and call status.
- **Confirmed Decision 3 (Dual Location Intelligence)**: Last 24-hour location tracking synthesizes two distinct telemetry layers:
  1. *Cell Tower Telemetry*: Base Transceiver Station (BTS) Cell ID, Location Area Code (LAC), signal azimuth, RSSI signal strength (dBm), and estimated coverage radius.
  2. *App-Level Location Telemetry*: Applications with location permissions (e.g., WhatsApp, Google Maps, Ride-Hailing, Social Media) recording precise GPS latitude/longitude, altitude, accuracy radius (meters), and app bundle identifier.
- **Confirmed Decision 4 (Credit Scoring & Behavioral Risk Profile)**: Integrated Telco Alternative Credit Scoring module evaluating numerical credit score (300-850), payment timeliness, SIM tenure age, device stability, and fraud risk index.
- **Confirmed Decision 5 (Top 5 Apps Intelligence Summary)**: Dual ranking widgets displaying Top 5 Most Opened Apps (launch frequency) and Top 5 Highest Data Consuming Apps (GB/MB volume).

## 1. Overview & Core Concept

### What It Does
The IPDR Real-Time Usage Monitoring System ingests, indexes, and visualizes network session data generated by mobile and fixed broadband subscribers. It enables network operators, risk assessment teams, and lawful intercept analysts to:
- Instantly cross-reference and navigate communication graphs: clicking a phone number in a WhatsApp call log pivots immediately into that target's full IPDR intelligence dossier.
- Analyze clean, deduplicated VoIP call logs displaying total call frequency counts alongside granular individual call durations for every interaction.
- Correlate dynamic IP allocations with physical hardware (IMEI), SIM identities (IMSI/MSISDN), and legal citizen profiles (Civil Number ID).
- Inspect high-resolution session timelines, application data quotas, encrypted VoIP signaling logs (WhatsApp calls), and 24-hour physical movement patterns across cellular sites and application GPS pings.
- Assess subscriber financial trustworthiness via Telco Alternative Credit Scoring and Top 5 app usage habits.

### Target Audience & Persona
- **Telecom Network Operations Center (NOC) Engineers**: Monitoring bandwidth spikes, network abuse, and routing anomalies.
- **Telecommunication Compliance & Intelligence Analysts**: Analyzing communication networks and call frequency patterns between subscribers.
- **Telecom Risk & Credit Underwriters**: Assessing subscriber creditworthiness for postpaid contracts and device financing.

## 3. Key Product Decisions & Trade-Offs

- **Decision 1: WhatsApp Call Grouping by Contact**:
  - *Chosen Approach*: Group raw call logs into distinct contact conversations with aggregate metrics (call frequency, total time) and expandable individual call logs with individual durations.
  - *Why*: Eliminates clutter and duplicate contact rows while maintaining full visibility into each separate call's exact talk time.
- **Decision 2: Seamless Graph Navigation via Clickable Numbers**:
  - *Chosen Approach*: Every phone number in the call log is a navigable link that updates the active subscriber in state and transitions the view smoothly to the clicked number's complete IPDR profile.
  - *Why*: Enables rapid pivot investigation commonly needed during lawful interception and fraud tracing without having to copy-paste numbers back into the search bar.
- **Decision 3: Telco Credit Scoring & Dual Location**:
  - *Chosen Approach*: Verifiable telecom behavioral factors displayed with score gauge and dual-layer map with Cell Tower LAC/CID alongside App GPS breadcrumbs.

## 4. Technical Architecture & Data Strategy

### WhatsApp Aggregated Data Model

```typescript
interface IndividualCallRecord {
  id: string;
  timestamp: string; // ISO 8601
  callType: 'AUDIO' | 'VIDEO';
  direction: 'OUTGOING' | 'INCOMING';
  durationSeconds: number; // Individual call duration e.g. 842s -> "14m 02s"
  durationFormatted: string;
  relayServerIp: string;
  relayPort: number;
  protocol: 'SRTP' | 'STUN/UDP' | 'TURN';
  status: 'COMPLETED' | 'MISSED' | 'DROPPED';
  packetLossPercent: number;
}

interface WhatsAppContactCallGroup {
  contactPhone: string; // Clickable MSISDN e.g. "+62 812-9988-7711"
  contactName: string;
  contactCivilId?: string;
  linkedSubscriberId?: string; // Target ID for navigation
  totalCallsCount: number; // Frequency of calls (e.g. 6 calls)
  outgoingCallsCount: number;
  incomingCallsCount: number;
  totalDurationSeconds: number;
  totalDurationFormatted: string;
  lastCallTimestamp: string;
  individualCalls: IndividualCallRecord[]; // Each call with its own exact duration
}
```
